# Casos de prueba funcionales — Tags

Casos manuales para las funciones de tags (etiquetas). Cada caso referencia el
requerimiento funcional (RF) de `docs/requerimientos.md` que verifica.

| ID | RF | Precondición | Pasos | Resultado esperado |
|---|---|---|---|---|
| CP-TAG-01 | RF-015 | Usuario autenticado que puede crear publicaciones en el muro. | 1. Abrir el muro. 2. Crear una publicación nueva. 3. Escribir una etiqueta en el campo de etiquetas. 4. Guardar la publicación. | La etiqueta queda asociada a la publicación al guardarla. |
| CP-TAG-02 | RF-015 | Usuario autenticado que puede crear publicaciones; en Moodle existen tags predefinidos. | 1. Abrir el muro. 2. Crear una publicación nueva. 3. Elegir un tag predefinido de Moodle en el campo de etiquetas. 4. Guardar la publicación. | El tag predefinido queda asociado a la publicación al guardarla. |
| CP-TAG-03 | RF-015 | Usuario autenticado con una publicación propia sin etiquetas en el muro. | 1. Abrir el muro. 2. Editar la publicación propia. 3. Escribir una etiqueta en el campo de etiquetas. 4. Guardar los cambios. | La etiqueta queda asociada a la publicación editada al guardarla. |
| CP-TAG-04 | RF-015 | En el muro hay una publicación con etiquetas asociadas, creada por otro usuario. | 1. Iniciar sesión con un usuario distinto del autor. 2. Abrir el muro. 3. Revisar la publicación. | Las etiquetas de la publicación se ven en el muro. |
| CP-TAG-05 | RF-016 | En el muro hay publicaciones con una misma etiqueta y otras sin ella. | 1. Abrir el muro. 2. Hacer clic sobre esa etiqueta en una publicación. | El listado se recarga y muestra únicamente las publicaciones que contienen esa etiqueta. |
| CP-TAG-06 | RF-016 | El muro está filtrado por una etiqueta específica. | 1. Elegir la opción de limpiar el filtro o restablecer el muro. 2. Revisar el listado. | El muro muestra nuevamente todas las publicaciones disponibles, sin filtro. |
| CP-TAG-07 | RF-017 | Estudiante autenticado y etiqueta académica visible en una publicación. | 1. Iniciar sesión como estudiante. 2. Abrir el muro. 3. Localizar una etiqueta académica. 4. Seleccionar "Seguir tag". | El sistema registra el seguimiento y muestra que el estudiante ya sigue la etiqueta. |
| CP-TAG-08 | RF-017 | Estudiante autenticado que ya sigue una etiqueta académica. | 1. Iniciar sesión como estudiante. 2. Abrir el muro. 3. Localizar la etiqueta seguida. 4. Comprobar el estado de seguimiento. | La etiqueta aparece como seguida y no se crea un seguimiento duplicado. |
| CP-TAG-09 | RF-017, RF-021 | Estudiante que sigue una etiqueta académica y existen publicaciones asociadas a ella. | 1. Iniciar sesión como estudiante. 2. Acceder al feed personalizado. 3. Revisar las publicaciones. | Se muestran las publicaciones de la etiqueta seguida, junto con las de usuarios seguidos, ordenadas por fecha. |
| CP-TAG-10 | RF-021 | Estudiante que sigue una etiqueta académica y docente con permiso para publicar. | 1. Iniciar sesión como docente. 2. Crear una publicación con la etiqueta seguida por el estudiante. 3. Guardarla. 4. Iniciar sesión como estudiante. 5. Actualizar el feed personalizado. | La nueva publicación aparece en el feed personalizado del estudiante. |
| CP-TAG-11 | RF-016 | Estudiante autenticado y publicaciones con distintas etiquetas académicas. | 1. Iniciar sesión como estudiante. 2. Abrir el muro. 3. Seleccionar una etiqueta académica seguida. 4. Revisar las publicaciones. | El muro muestra únicamente las publicaciones asociadas a la etiqueta seleccionada. |
| CP-TAG-12 | RF-017 | Estudiante autenticado que sigue una etiqueta académica. | 1. Abrir el muro. 2. Localizar la etiqueta seguida. 3. Seleccionar "Dejar de seguir". 4. Acceder al feed personalizado. | El seguimiento se elimina y las nuevas publicaciones de esa etiqueta dejan de aparecer por ese seguimiento. |
| CP-TAG-13 | RF-017 | Docente autenticado con acceso al muro y una etiqueta académica visible. | 1. Iniciar sesión como docente. 2. Abrir el muro. 3. Localizar una etiqueta académica. 4. Seleccionar "Seguir tag". | El docente puede seguir la etiqueta si tiene los permisos correspondientes y el sistema registra el seguimiento. |
| CP-TAG-14 | RF-017 | Estudiante y docente autenticados con acceso autorizado al muro. | 1. Iniciar sesión como estudiante y comprobar la opción de seguir etiquetas. 2. Cerrar sesión. 3. Iniciar sesión como docente y comprobar la misma opción. | Ambos roles pueden utilizar el seguimiento de etiquetas según sus permisos, sin acceder a funciones no autorizadas. |
